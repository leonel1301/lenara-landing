# Broken Compass — sprite sheets

Game production assets for Broken Compass. These files are kept separate from the marketing presentation art in `../presentation/`.

## Files

- `protagonist-sprites.png` — eight-direction locomotion reference
- `action-sprites.png` — push, crouch, talk, damage, death, and reunion reference
- `npc-sprites.png` — modular companion cast on a reusable skeleton
- `biomes-tileset.png` — nine-biome environment atlas
- `music-prompt-elevenlabs.txt` — original ElevenLabs generation prompt

All images are 1536 × 1024 PNG concept atlases.

## Production note

Clean backgrounds, slice frames on a fixed grid, and export engine-ready sheets with one shared origin and collision box per character.
